# Telegram-бот текстильной компании

## Коротко о проекте (для заказчика и пользователей)
Этот проект — Telegram‑бот для клиентов текстильной компании. Он помогает быстро получить прайс‑листы и остатки по городам, скачать каталог готовых изделий и связаться с компанией.

### Что умеет бот
- 📚 **Прайс‑лист** тканей и фурнитуры (файлы XLSX).
- 📦 **Наличие по городам** (Москва / Санкт‑Петербург) в виде файлов XLSX.
- 📸 **Каталог готовых изделий** (категории в виде файлов).
- 📇 **Контакты, адрес, режим работы, реквизиты** — в одном месте (с возможностью изображения).
- 📨 **Заявки и вопросы**: звонок, вопрос, сообщение руководителю, ошибка.
- 📣 **Новости, акции, распродажи** с предпросмотром перед рассылкой.

### Как пользоваться (самое простое объяснение)
1. Откройте бота и нажмите **/start** — появится главное меню.
2. Выберите нужный раздел кнопками:
   - **Прайс‑лист** — скачивание файла с прайс‑листом.
   - **Наличие** — скачивание файла остатков по Москве или Санкт‑Петербургу.
   - **Каталог готовых изделий** — файл с изделиями по выбранной категории.
   - **Контакты / Как проехать / Реквизиты** — полезная информация о компании.
   - **Заявка на звонок / Задать вопрос / Связь с руководителем / Сообщить об ошибке** — для обратной связи.

### Важно знать заказчику
- Рассылка уходит всем активным пользователям, которые **не заблокировали** бота.
- Предпросмотр рассылки всегда совпадает с тем, что увидят пользователи.

## Админ‑панель (объяснение простыми словами)
### Кто такой администратор
Есть **главный администратор** (суперадмин). Он выдаёт доступ остальным. Обычные пользователи админ‑разделы не видят.

### Как получить доступ
1. Введите команду **/getadmin**.
2. Введите **логин** администратора.
3. Введите **пароль** администратора.

После этого появится кнопка **«Админ‑меню»** в главном меню (переключатель между режимами).

### Что умеет администратор
- **Загружать прайс‑листы** тканей и фурнитуры (XLSX).
- **Загружать остатки** по городам (Москва/СПБ) в XLSX.
- **Управлять каталогом готовых изделий**: добавить категорию, заменить файл, переименовать, удалить.
- **Редактировать контакты, адрес, режим работы, реквизиты** (можно добавить изображение).
- **Делать рассылки** — один универсальный текстовый пост с предпросмотром.

## Быстрая проверка, что всё работает
- Зайдите в админ‑панель через **/getadmin**.
- Добавьте тестовую категорию в «Каталог готовых изделий» и убедитесь, что файл появляется у пользователей.
- Отправьте тестовую рассылку с предпросмотром.
- Проверьте, что сообщение пришло на пользовательский аккаунт.

## Для программистов
### Технологии
- **Python 3**
- **aiogram** (Telegram Bot API)
- **SQLite** (данные и настройки)

### Структура проекта (кратко)
- `main.py` — запуск бота, регистрация обработчиков.
- `handlers/` — сценарии меню, админ‑панели, каталога и рассылок.
- `data/` — доступ к БД, справочники, ключи хранения файлов.
- `services/` — вспомогательная бизнес‑логика (рендер карточек, рассылки и т.д.).
- `structure/` — клавиатуры, состояния, форматирование сообщений.

### Где что хранится
- **База данных**: `data/database.sqlite3` (путь задаётся через `DB_PATH`).
- **Настройки контактов**: таблица `settings` в базе.
- **Каталог готовых изделий**: таблица `ready_catalogs` (хранит `file_id` и имя файла).
- **Логи**: `bot_debug.log`.

### Настройка окружения
Создайте файл `.env` на основе `.env.example` и заполните:
- `BOT_TOKEN` — токен Telegram‑бота.
- `ADMINS` — список ID суперадминов через запятую.
- `LOGIN_ADMIN` и `PASSWORD_ADMIN` — логин/пароль для команды `/getadmin`.
- `DB_PATH`, `PAGE_SIZE`, `TG_PROXY_URL` — дополнительные параметры (необязательные).

### Запуск (локально)
```bash
python -m venv venv
source venv/bin/activate  # для Linux/macOS
# venv\Scripts\activate  # для Windows
pip install -r requirements.txt
python main.py
```

### Загрузка файлов
- Загрузка выполняется из админ‑панели.
- Прайс‑листы и остатки хранятся как файлы и отдаются пользователю без парсинга.
