# Краткое описание проекта
Это Telegram‑бот для клиентов текстильной компании. Через него можно быстро посмотреть ассортимент и остатки в разных городах, получить файлы с готовыми изделиями и получать новости. Администраторы управляют наполнением и рассылками прямо из бота.

Основные возможности:
- просмотр каталога тканей и фурнитуры;
- просмотр наличия по городам;
- каталог готовых изделий, доступный в виде файлов;
- удобная админ‑панель внутри бота;
- рассылка акций и объявлений;
- система уровней администраторов.

# Как работает админ‑панель
**Кто такой администратор.** Есть главный администратор (суперадмин). Он единственный знает логин и пароль и выдаёт доступ остальным. Обычные пользователи не видят админ‑разделы.

**Как войти в админ‑панель:**
1. Ввести команду `/getadmin`.
2. Ввести логин администратора.
3. Ввести пароль администратора.
После этого откроется меню администратора. Логин и пароль знает только главный администратор и передаёт их вручную. Для обычных пользователей эта возможность скрыта.

# Каталог готовых изделий
Каталог состоит из категорий. Каждая категория — это файл таблицы. Название категории для пользователя совпадает с названием файла.

Как работает администратор:
- добавляет новую категорию: вводит название и прикрепляет файл;
- может заменить файл на обновлённый;
- может переименовать категорию;
- может удалить категорию.

Как это видит пользователь:
- нажимает кнопку «Каталог готовых изделий»;
- выбирает нужную категорию;
- получает файл с описанием изделий.

# Публикация акций и объявлений
**Промо по товару.** Администратор выбирает, откуда брать товар: из каталога (без города) или из наличия (с выбором города). Затем выбирает сам товар, ставит тип акции (акция, новинка или распродажа), добавляет текст при желании, может прикрепить кнопку со ссылкой. Перед отправкой видит предпросмотр, затем подтверждает рассылку. Предпросмотр выглядит так же, как сообщение у пользователей. Рассылка уходит всем пользователям бота.

**Объявление без товара.** Подходит для общих новостей и распродаж. Выбор товара не нужен: достаточно текста и типа акции. Есть предпросмотр и подтверждение перед отправкой.

# Как самостоятельно убедиться, что всё работает
- Зайдите в админ‑панель через `/getadmin`, используя логин и пароль.
- Добавьте тестовую категорию в каталоге готовых изделий: придумайте название, загрузите пробный файл и убедитесь, что он появляется в списке у пользователей.
- Отправьте тестовое объявление без товара: выберите тип, введите текст, посмотрите предпросмотр и подтвердите отправку.
- Откройте бот с пользовательского аккаунта и убедитесь, что сообщение пришло. Если кто‑то блокировал бота, ему сообщения не доходят — это нормально.

# Важные пояснения для заказчика
- Рассылка приходит всем, кто не блокировал бота.
- Если пользователь заблокировал бота, сообщение к нему не попадёт, но на работе бота это не сказывается.
- Предпросмотр всегда совпадает с тем, что увидят пользователи.
